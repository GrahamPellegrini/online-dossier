Class starting-point check

DGP0959 · Session 1 · Five-minute optional diagnostic · Graham Pellegrini

This helps the tutor choose demonstrations and pace. It is not graded. You may skip any question. Do not include your name, email address, passwords, account screenshots or subscription codes.

  1. AI experience: Never used it / Tried once or twice / Use sometimes / Use most weeks.
  2. Tools used: ChatGPT / Gemini / Copilot / Document or research assistant / Image or slide tool / Other / None.
  3. Can you start a chat today? Yes / Not yet / Unsure / Prefer to use an example response.
  4. Account access: Personal free account / Personal paid account / Activated UM account / UM account not activated / Unsure. Tick all that apply; do not write the address.
  5. Device and internet: Ready / Need help / Will work with a partner or paper example.
  6. Useful tasks: Understanding material / Revision notes / Finding sources / Writing messages / Planning / Presentations / Tables and data. Pick two.
  7. Checking confidence: I can spot a weak answer / Sometimes / I need a demonstration.
  8. Optional AI for All route: Already enrolled / Interested / Not interested / Unsure whether eligible. Do not supply eID information.
  9. Your field or interest: Optional short description, such as science, business, languages or student societies.
  10. One goal: “By the end of this course, I would like to…”

Quick baseline task

Read this fictional result: “You are available Monday 17:00–18:00. Study Monday 17:00–19:00 to finish your report.”

What needs correcting? Which part of the supplied information would you use to check it?

Tutor use

Use a show of hands, paper sheet, or VLE questionnaire. If using the VLE, check whether responses are linked to student identities before describing it as anonymous. Do not publish individual responses in the online dossier.

Summarise only the class totals for experience and access. Use the baseline answer to decide how much checking needs modelling. Pairing is optional: students with access can operate a tool while their partner checks; swap roles. Students using saved outputs can perform the same checking task.

If several students need access help, show the setup guide for five minutes, then continue with saved outputs. Provide separate follow-up support so setup does not consume the workshop. Ask for access difficulties privately where possible.

Graham Pellegrini | University of Malta DegreePlus
