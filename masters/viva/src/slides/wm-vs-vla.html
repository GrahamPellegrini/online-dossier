A VLA generates. A world model predicts consequences.

VLA (vision-language-action)

Still a policy at heart: scene in, movement out.

Generative like an LLM, so it can produce a confident but unfaithful movement.

World model

Learns in a compact latent space, not raw pixels.

Predicts what happens after an action, so it can compare movements before making one.

The world model imagines where each movement leads, and keeps the one that opens the lock.
